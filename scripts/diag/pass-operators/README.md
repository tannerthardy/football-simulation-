# Pass-side operators

Measurement code for the pass game, sim against NFL with one operator per question. No engine change lives here.

**Inputs.**
- **Sim panel scripts** (`first-pressure.ts`, `backs-clock.ts`, `press.ts`, `route-start.ts`) read the saved matched-restage panel `out/matched-restage/seed7.json` and `seed11.json` (capture with `scripts/diag/matched-restage.ts capture <seed>`). They replay each dropback with 4 dice shifts: about 732 dropbacks.
- **Grid scripts** (`pressure-grid.ts`, `mug-grid.ts`) build their own plays and write JSON rows to the path given.
- **NFL twins** (`nfl_*.py`) read BDB 2025 tracking, e.g. `python3 -I scripts/diag/pass-operators/nfl_press.py <bdb dir> 1,2,3`.

Run sim scripts from the repo root with flags as env, e.g. `WR_SNAP=1 npx tsx scripts/diag/pass-operators/press.ts`.

| `read-choice.ts` | where each target sat in the QB's read order (read #1 / later / outlet / off-order) and how often each route is read #1 | — |

| `yac_split.py <off> [...] -- <on> [...] --- <nfl.jsonl.gz>` | (common format, NFL and sim alike; C14) YAC split into yards before first contact and after it, by catch depth, with catch speed, nearest defender, catch-to-contact time and the no-contact share | itself on the NFL file |
| `catch_pursuit.py <off> [...] -- <on> [...] --- <nfl.jsonl.gz>` | (common format, NFL and sim alike; C14) on 0-10 yd catches, the nearest defender's gap, speed and closing at the catch, and the gap 0.5 / 1.0 s later | itself on the NFL file |
| `press_release.py [--bdb <dir>] <plays.jsonl.gz> [...]` | (common format, NFL and sim alike) the widest WR on a go/fade (NFL `routeRan` GO from player_play; sim `players[i].route`) with a defender within 3 yd at the snap: depth, position along / across the corner and both speeds at 0.5 s steps to 3.0 s, when he gets level with the corner, contact at the line; all / man / zone / Cover 1 | itself on the NFL file |
| `press_jam.py <plays.jsonl.gz> [...]` | (common format, NFL and sim alike) pressed WR (a defender within 2.5 yd at the snap), wide / inside, man / zone: the corner's first step (ground given and lateral at 0.3 / 0.5 s), contact in the first 1.0 s (centres within 1.0 yd), the receiver's speed at 0.5 / 0.8 s, path, depth and lateral by contact / no contact, and when he is level with the corner | itself on the NFL file |
| `trail.py [--ball nfl-ball.jsonl.gz] <plays.jsonl.gz> [...]` | (common format, NFL and sim alike; C14) on-target throws whose nearest defender at arrival is 1-2 yd away, trailing and in phase: his closing on the catch point and speed change over the last 0.3 s, final gap; completion, and YAC / first contact after catches, split by whether he closed hard or stayed on the hip | itself on the NFL file |
| `placement.py [--ball nfl-ball.jsonl.gz] <plays.jsonl.gz> [...]` | (common format, NFL and sim alike; C14) where tight and trailing-coverage balls arrive: the incoming flight line's closest approach to the receiver (outcome-independent), along / across his run and toward / away from the nearest defender, and completion by that offset and side | itself on the NFL file |

| `nfl_pass_penalties.py <play_by_play_2022.csv.gz>` | NFL flags per 100 passes (DPI, OPI, defensive holding, illegal contact; offensive holding for scale), short / deep, from nflverse play-by-play: BDB leaves out plays wiped out by a penalty. | `lane.py <plays.jsonl.gz>` | (common format, NFL and sim alike) a defender 1.5-4 yd ahead in a WR/TE's lane before the throw: offset at passing, going around / across, when it began, closest distance (touching < 0.7 yd), speed through, by depth; and for a retreating defender | itself on the NFL file |
| `stem.py <plays.jsonl.gz>` | (common format) WR/TE downfield stems: speed at 0.5 / 1.0 / 1.5 / 2.0 s by press / off and slot / wide, first-0.5 s acceleration, throttle before the break | itself on the NFL file |
| `press_depth.py [--plays plays.csv] <plays.jsonl.gz>` | (common format) the defensive back's depth off the outside WR at the snap, distribution by coverage family and down (sim down/distance from sim-export's cell) | itself on the NFL file with BDB plays.csv |

Contact in the YAC operators is geometric and shared with Defense's `scripts/diag/defense-yards/yards.py`: a defender's centre within 1.0 yd of the carrier, on 0.1 s frames. Mine measures stages from the catch; theirs measures at +10 yd after the catch. Results: `docs/reviews/2026-11-10-yac-decomposition.md`.
