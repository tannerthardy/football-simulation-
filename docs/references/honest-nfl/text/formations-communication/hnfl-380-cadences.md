RHYTHMIC CADENCE = AN AUDIBLE CUE IN WHICH THE QB USES THE “COLOR-NUMBER” (EX. “WHITE 80”) CUE IN

A TRULY RHYTHMIC MANNER TO SYNCHRONIZE THE SNAP OF THE BALL. PLAYERS OUTSIDE OF THE CORE ARE

USING A VISUAL CUE OF THE CENTER SNAPPING AND THE NEAR OT COMING OUT OF THEIR STANCE.

“WHITE 80, WHITE 80, SET HUT”

NON-RHYTHMIC CADENCE = AN AUDIBLE CUE IN WHICH THE QB USES THE “COLOR-NUMBER” CUE IN A NON-

RHYTHMIC FASHION TO KEEP THE DEFENSE FROM TIMING THE SNAP WHILE WE KEY IN ON HEARING THE

TRIGGER WORD ON THE CALLED SNAP COUNT. PLAYERS OUTSIDE THE CORE USE A VISUAL CUE.

“WHITE 80, WHIIIINNINITE 80, SET HUT”

SILENT COUNT = A VISUAL OR PHYSICAL CUE IN WHICH THE QB USES A “LEG LIFT” OR INITIATES A “CENTER TAP”

TO KICKSTART THE SILENT SNAP COUNT.

“REDICK” = TELLS THE HUDDLE THAT WE ARE USING A DUMMY COUNT AND THAT THE 2% COUNT IS LIVE ON

A LIVE AUDIBLE CUE THAT CAN BE USED TO REMIND EVERYONE OF THE SNAP COUNT OR TO
