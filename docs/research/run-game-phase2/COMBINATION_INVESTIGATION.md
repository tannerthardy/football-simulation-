# F — What the original 53 jobs do, and do not, prove

**The actual number of genuine, feasible, useful missed blocks remains unidentified.** The tested interventions constructively verify zero such conversions; this is not an estimate of zero underlying opportunities. The audit now identifies the errors that a purported count would otherwise make, and preserves every job for challenge. Rebuilding the combination architecture from the original14/53 connection number would be premature.

The population is fixed: the first10 captured zone calls from each of historical seeds7–10,40 exact constructors,37 native snaps,53 initial linebacker jobs. It includes tight ends, safeties and nickel defenders where the installed backer responsibility uses them; “linebacker job” names the second-level role, not exclusively an LB roster position. Historical and current-source replays retain identical initial jobs. `JOB_LEDGER.md`, `job-ledger.csv` and `job-ledger.json` enumerate all53; the full native traces retain every later responsibility and contact.

## Why removing hands did not answer contribution

Sixteen historical loaded-job trials remove only selected original-member→original-target hand joints and pending strikes immediately before World steps. All16 plain/observed state comparisons pass. The intervention does not produce additional target access under the chosen reference geometry. That null result is **not** evidence that the blocks were useless: engagement-owned controller requests and body contacts remain, and the defender may still act as engaged. The experiment isolates force transmission under retained controller beliefs. A valid unblocked-defender counterfactual must also define restored defensive agency without silently changing unrelated random draws or assignments.
