# Experimental run/pass/awareness full-game checkpoint

Prepared October 14, 2026 (America/Phoenix); measurement receipts retain UTC.

**The recent work can be assembled into a reproducible experimental version,
but this combined bundle is not supported as a replacement for `develop`.**
Local improvements and a clean code suite do not establish better full-game
football. Ordinary runs worsen, interceptions rise and explosive YAC remains.
Nothing is merged, designated a baseline, or switched as GitHub's default.

**Do not call the closer rushing mean an improvement.** Run success falls in
all four matchup pairs. The spread/air pair's rushing mean rises, but its run
success still falls. Completion rate barely changes; the YAC tail remains large.
The reduced score does not establish better football, particularly alongside
more interceptions. Four games per arm cannot estimate seed variation or
certify league realism. Individual published controller improvements are not
all disproved or credited by this bundle-level result.

The read-only World-report observer also finds:

These counts flag an information/spacing/coordination question; body contact

need not be carrying at that instant. No collider/physics capacity changed.
The bundle does not isolate which contribution or changed history caused
those contacts. Use the saved own-state, role, contact and native-film evidence
before changing strength, sensing, or lane rules.

All eight games finish, but **five experimental ordinary plays hit the 25-second
native play cap versus seven controls**. Those are preserved system-capped
plays, not natural football endings or a claimed solution to long-contact holds.

## Film and concrete witnesses

**1,083 ordinary scrimmage clips and 54,891 recorded positional frames** are
retained across all eight film rooms. Six two-point tries have their inputs/
contact observations in the raw packets but the existing game recorder does
not film them; kicks/special teams remain in the logs. Standard telemetry shows
actual jobs, requested motion and engagement links, not full acquired-picture,
body-support or exact hand-force internals. Body facing is not measured gaze.
All eight films load, decompress and seek in Chromium with zero page errors.

The 59.2-second reel uses a fixed offline selection recipe. No play is rerun:
first matched opening pair, first stretch run, median run, worst run, first

available in the full film rooms. [Exact clip selection](../../data/reviews/current/experimental-game-checkpoint/film-selection.json)

  is a changed result, not by itself proof of better line/runner decisions.

  the lowest-gain designed run rather than hiding ordinary/adverse execution.
- Experimental power/zone P36: All Hitch produces **88.8798 YAC**, catching

  There is no recorded grip-retention event to strengthen in this example;

alongside each film. These are reproducible measurement packets, not serialized
mid-play World restart states.

## Verification, cost and next decision

Final frozen verification: **1,850 TS checks in 152 files, 145 Python checks,
typecheck and build pass; zero skipped phases and unchanged inputs**.
The [unaltered final launcher receipt](../../data/reviews/current/experimental-game-checkpoint/verification/combined-final.json)
is the shared evidence; contributors should reuse it rather than rerun it.

An initial focused check found six partial stalk mocks missing the new installed
alignment metadata. Only the mock was completed; all assertions remain.
The first combined run then found an observer dropping #13's new fifth assessment
argument. A variadic forward restores exact result/body/mind/perception/RNG
neutrality; the 12 affected checks pass. The corrected validation input justified
the final full run. Both original failure receipts/logs are preserved, not
relabeled passes. Runtime source did not change between combined attempts.

Cost: the initial failed combined commands cost 210.66s; final 206.63s; affected
checks 10.57s. The **eight-game batch takes156.79s wall**, including exports,
of which 144.28s is native game simulation. Total new launcher command time
including preparation/games is 584.22s. Film/report/viewer work adds zero plays.
These are costs for different game histories/workloads, not speed benchmarks.
No favorable early stop, automatic larger roster ladder, extra game campaign,
or experimental-physics promotion occurred.

**Keep the version available for inspection, not wholesale adoption.** The next
bounded question is the information/spacing/run-coordination interaction,
starting from saved first divergences and opposing controls. The no-contact YAC
witness is a separate containment question. A concrete mechanism correction
should precede another game batch. This result does not reopen every parked
experiment or justify global tackle/block strength tuning.

Publication adds docs, receipts and films only after the frozen commit. Original
implementation/rejected-trial branches, their evidence, active work, accepted
develop and historical 4ded6b6 remain intact.
