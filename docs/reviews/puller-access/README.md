## Footwork and linebacker conclusions

The useful common sequence is **clear the actual surface, acquire the required
shoulder, then keep the defender's route to the runner controlled through arrival**.
It is not one universal pull shape:

- A short kick/trap fits an approaching first-level shoulder; a wrong-arm can
  justify a log. K01 and P02 demonstrate real loaded work without extra force.
- A force puller must clear the outside pin surface, then collect observed
  support. A completed clearance step should not restart because pursuit bends
  inside an old coordinate. It also does not guarantee that deep support is
  reachable before the runner's first threat.
- A wrapper needs a coherent next job, compatible paths around the kick/log
  and a reachable strike surface. Prioritizing him alone can transfer the
  traffic or leave another blocker duplicating first-level work.
- Buck's two guards need compatible spacing. The tested extra-depth removal
  is not a production solution despite earlier arrival.

The LBs are not uniformly standing still. In B01 Mike's lateral request changes
from about+.2yd/s at .50 to−9.3 at1.00; at1.50 he consumes a .20s-old back picture
with lateral velocity−2.80 and possession false during the mesh. Will/Sam also
request flow. Those requests are executed through normal turning, support,
traffic and contact; they are not instantaneous achieved speed. In Counter,
initial counter action and later pulling/back pictures can disagree. The saved
trace retains those consumed pictures instead of attributing every reversal to
bad reaction or tuning LBs slower to help the offense.

No native cause here establishes a new LB controller correction or a physical
execution defect. One source limitation stays visible: default live-gap departure
classification still consults an OL's live engagement flag in its marginal-depth
branch. The existing PULL_CUE research addresses that information question but
remains off; this pass neither activates it nor certifies all flow inputs as clean.
That shared awareness question is separate from earned defensive access here.
Literal anatomical steps are not modeled; these conclusions concern attainable
body tracks, facing, support and useful contact.
