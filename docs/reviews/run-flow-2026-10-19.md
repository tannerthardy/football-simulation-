# Acquired run flow: linebackers and defensive line — 2026-10-19 America/Phoenix

Two distinct controller restrictions explain part of the missing flow. Free
linebackers can choose lateral run flow while being ordered to keep square
shoulders, so the unchanged body permits only shuffle capacity. Blocked first-level
defenders can keep recentering on a blocker shoulder after an acquired carrying
back has left that fit laterally. These are movement-technique and objective
errors after run recognition, not proof that recognition alone is too slow.

Two independent corrections have focused and native support and are submitted for
Run/controller review. Neither is merged or statistically calibrated. Some run
endings worsen; their evidence remains below. #158's power-edge entry proposal,
all timing changes and #153's broader experiments remain separate.

## DL correction: follow an acquired run after it has left the fit

Only `runContactRead`'s lateral objective and its held flow metadata change,
plus consumption of that flow by the existing run-rep planner. For an interior first-level
non-lag player, the new mode requires:

- existing run belief/reading;
- personally acquired RB carrying=true **and** QB carrying=false;
- known finite picture ages within own reaction time plus two ordinary decisions;
- existing developed lateral-motion threshold, |vy|>1.5yd/s;
- that observed back still deeper than the existing LOS−1.6 declaration surface,
  but already past the defender laterally by the existing body/reach margin.

The objective stays inside the observed runner by that physical margin and
retains own depth. The existing planner advances the moving point once over two
decisions. Target, mode and observed flow are selected together on the existing
`SnapMind.aim` cadence; there is no new persistence timer or permanent run latch.
The old shallow-runner/contact-pursuit ownership remains. All edge box/spill,
lag, mesh uncertainty and contradictory/stale pictures do not gain this mode.

TOSS first changes DT_W at1.55s. His actual consumed RB picture is carrying=true,
age0.30s, y24.494/vy−1.979; QB carrying=false is also0.30s old. This evidence
exists before the change. At2.50s the same tackle, `SD-DT2`, is at y24.890 versus
25.812, **0.92yd farther toward the ball**, with unchanged feet/hand limits.
At3.0s a fresh DT_W (`SD-DT5`) gains about **2.00yd of lateral position**.
The frontside end's original missed reach/body-contact sequence remains; the
patch does not manufacture a shed or strengthen the hand joint.

Focused hidden-reality controls independently change live QB/RB possession,
motion and private give/keep flags while preserving acquired pictures: the new
flow request is invariant. Unknown, contradictory and stale pictures oppose it;
new acquired evidence changes the request on the normal decision cadence.
This repairs the new consumer's information contract, not all legacy contact
code: authoritative carrier selection and other awareness shortcuts remain outside
this patch.
