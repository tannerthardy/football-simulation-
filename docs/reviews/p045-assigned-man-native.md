# Acquired assigned-man retention: native trial parked

October 15, 2026 (America/Phoenix).

**Do not integrate this version.** Retaining the assigned receiver with ordinary
`track` preserves running momentum, but the native P045 catch approach becomes
wider and less aligned. It later closes better without making contact. The only
fresh YAC reduction has identical actual tackler entry and different stochastic
grasp execution; it is not evidence that this controller improves approach.
The prototype and its tests are archived. Active source/tests exactly match
accepted develop `8c891f4cf887b54297efbbc4c7993ba5e2f318b5`.

One request branch follows the existing reachable-ball decision. When no

earlier cushion/hip-turn prototypes are not combined with this trial. Nothing

## Verification, cost and decision

**42 affected TypeScript checks pass**: catch-phase behavior, reach, coverage
mechanics and coverage rules. The new contracts cover achieved same-body
movement, reused acquired evidence/no extra draw, hidden-target invariance,
an observed plant, reachable ball, genuine alternative receiver window and an
unassigned defender. Accepted-source red evidence has two new assertions
failing and 11 passing; no preserved assertion was relaxed or removed.
Prototype additions are archived after rejection; accepted tests are restored.

**32 native play executions**, comprising selected three cases × two arms ×
record/plain, four fresh cases × two arms × record/plain, and one passive fresh
execution audit × two arms × audited/plain. Launcher commands total **25.316 s**,
including focused checks and the expected red run. The fixture builder and
saved-result report add no simulations. Zero prefixes, full games, broader
roster campaigns or full suites. Integration's passing accepted suite is reused;
no full-suite/typecheck promotion campaign is needed for a rejected prototype.

All 44 flags, unchanged ordinary World defaults, Node22.23.3, lock, input,
collector and source fingerprints are embedded per arm/receipt. The collector's
legacy audit header called its clip selector `model`; the actual runtime model
was null and both signatures match. Publication corrects that metadata name;
no policy or measurement is changed by the correction.

**Decision: parked, not ready for integration.** Useful later speed retention
does not outweigh the worsened P045 catch geometry and absent attributable
fresh contact benefit. No additional batch is justified to force a favorable
ending. The smallest next controller experiment would retain the assigned-man
objective with the existing bounded interpretation of acquired hip turns/plants,
rather than raw delayed-velocity tracking. That is a separate candidate, not a
vision/capacity change, and still needs P006/P010 and observed-cut controls.

## Reproduction

accepted pin in an isolated branch. Applying the controller patch reproduces
the candidate source hash above. The frozen fresh fixture can be regenerated
with `p045-assigned-man-transfer.mjs` (no plays executed). Native comparison:

```sh
npm run baseline:run -- --candidate -- node --import tsx scripts/diag/p045-native.mjs flight data/reviews/current/p045-defensive-inputs.json out/native-new/selected.json.gz
npm run baseline:run -- --candidate -- node --import tsx scripts/diag/p045-native.mjs transfer data/reviews/current/p045-assigned-man-fresh-inputs.json out/native-new/fresh.json.gz

```
