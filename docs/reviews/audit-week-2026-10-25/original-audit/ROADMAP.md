# Revised implementation roadmap

Proposed for the next review, October 23, 2026. Experimental source: `c4a03f6463eacb23ce63d01bd32b4f8b547b9bc0`. Final develop `ccdb69cba81e07c578f607ff1bf8ce0efe2edc68` adds only VIEW-1 documentation; simulation code is identical. This document revises the [first audit's A01–A21 proposals](https://github.com/tannerthardy/football-simulation-/blob/73a800464a7b2a057a2f4df59d772c89bbd87b21/artifacts/audit-2026-10-25/Football-Sim-Deep-Audit.zip); it does not amend the repository's approved PLAN, ranked gaps, assignments or merge rules. Read the [revised review](REVIEW.md) and linked investigations for evidence. These are actionable handoff briefs for the coordinator to select, not automatic assignments.

The next milestone is a trustworthy football experiment: a supported call and selected lineup reproduce, a player's action can be followed from acquired evidence through physical response, and changing one meaningful input has an explainable effect. A universal decision chooser is no longer part of the success criterion.

Effort classes describe **focused engineering and review effort**, using agents: **S**, up to two days; **M**, three to seven days; **L**, two to four weeks; **XL**, research with unresolved scope. Estimates are uncertain, are not calendar commitments, and should not be summed into a delivery date. Each brief separates a first bounded delivery from later expansion where necessary.

## Sequence through the existing lanes

Retain the October 22 operating model: normally G1/defense, G2/run and G3/coverage, with the already authorized G5/trenches-physics exception. Tools supplies those owners with measurements and reproducible inputs. This audit does not create an architecture lane, another workboard, or 21 simultaneous projects.

**Review and cycle 0:** tools repairs false certification and canonical input identity, then packages the existing neutral trace/restorer for one live consumer. Refresh gap entries with current source and evidence. Each football owner nominates one failure and one legitimate opposing example. Preserve active valid G5 work; no finding here warrants restarting its program.

**First repair cycle:** prioritize the small action-cache repair in run/coverage, the two possession consumers in coverage/defense, and contact acquisition in defense/physics as slots and shared-file ownership permit. One owner lands each shared-boundary change, with the affected lane reviewing. Sequence overlapping edits instead of creating separate incompatible fixes to `defense.ts` or tackle geometry. Tools remains supporting work, not a parallel platform project.

**Next freed slot:** run a bounded pursuit forecast/request comparison, retaining current capacities. A small trait/lineup truthfulness slice can accompany tools work. Only then revisit a genuine choice failure that survives corrected knowledge, action lifetime and execution. A local help predicate is the baseline against which any broader adaptation design must earn its cost.

**Later cycles:** broaden supported concept/protection families, physical-law repair and conditional measurement as their actual dependencies permit. Large exploit searches, richer cognition and product expansion remain conditional. Do not require every lower layer to be perfect before testing installations; do require honest capability boundaries before claiming matchup realism.

The revised milestones are: M0, evidence and input identity are trustworthy; M1, ordinary failures can be localized without bespoke collectors; M2, valid commitments persist and obsolete actions change coherently, with useful transfer; M3, supported trait/concept experiments have credible causal meaning. Sharing a chooser is optional at every milestone.

Schedule a decision checkpoint after one or two bounded repair cycles: test independent active opportunity/discipline cases across roles. Do not let contract cleanup indefinitely defer the adaptation question. VIEW-1, merged during packaging, fits A03/A04/A10: start with structured play/player/time annotations and trustworthy overlays; reserve a separate interactive scenario application for a later demonstrated need.

## Explicit disposition of A01–A21

### A01 — Repair evidence validity and wording

**Keep immediate; S. Owner: tools.** Deliver explicit missing, incompatible, insufficient and qualified comparison states. The empty mechanics witness must not certify a match. Replace unjustified “noise” or “real move” language with what the sample actually resolves; retain denominators for rare events. Put fast offline operator tests in the relevant CI path.

**Accept:** empty/missing evidence fails qualification while adequate matching evidence still qualifies; ordinary game execution is unchanged. **Opposing control:** a real match remains a match. **Stop:** once false assurance and ambiguity are corrected; do not replace the statistical framework. Evidence: [measurement investigation](measurements.md).

### A02 — Refresh current gap evidence and closure definitions

**Combine with A01's review delivery; S. Owner: coordinator, tools prepares.** Pin source, default flags, operator and input cohort for each active claim. Distinguish merged mechanism, partial repair and demonstrated closure. Historical “now” tables stay explicitly historical. New findings become proposed evidence updates, not silent target changes.

**Accept:** a new owner can locate current evidence, responsibility and the next discriminating question from the existing gap entry. Each closure preserves a named valid opposing behavior. **Stop:** no new tracking system or mandatory paperwork; update only entries whose current decision changes. Approval of priorities remains the existing review decision.

### A03 — Evaluate and use film scouts

**Keep, narrow; M first cycle. Owner: tools with football reviewers.** Reuse merged detectors and saved replay identities. Review uncapped alerts and independently sampled ordinary plays; record useful, false and uncertain nominations. Ask agents to establish the first suspect interval before escalating a short clip to Tanner.

**Accept:** nominations identify actor, input, concern and missing evidence; a legitimate coverage turn, contact-owned facing and unreachable far-side helper survive as opposing cases. **Stop/narrow:** a detector costs more review time than it saves. Do not optimize player behavior to erase alert counts or claim population recall from selected positives. Use the [film cases](film-cases.md).

### A04 — Selective decision and command-stage trace

**Combine first delivery with A10; M. Owner: tools plus one current consumer.** Record decision-time owner/target, consumed observation age, action/cache creator and deadline, forecast status, raw request, actual modifier differences, final request and endpoint owner. Separate interval start from physical endpoint. Capture only selected actors/windows.

**Accept:** neutral on/off repeats match complete results; P095's stale goal, P019's engagement-facing request and a valid spacing intervention are assigned to their actual stages. **Opposing control:** retained-but-uncalled cache P029 cannot be labeled executed error. **Stop:** no permanent all-player trace platform. The [neutral architecture collector](architecture.md) already demonstrates feasibility; reuse it.

### A05 — Enforce player knowledge at a narrow policy boundary

**Keep and narrow to duplicated possession acquisition; M pilot, L staged adoption. Owner: coverage/defense.** Introduce one explicit acquired holder/catch belief for both event-driven defender replacement and legacy `pursueIfLive` admission. Delaying only one is insufficient: native P002's four-arm comparison demonstrates the bypass. Preserve uncertain flight-based anticipation as a separate legitimate cue.

**Accept:** hidden holder changes do not affect either migrated path before evidence; acquired catch/loose-ball changes eventually do. Repeat each isolated no-op and the combined intervention. Preserve pre-catch coverage, fake handoffs, unseen catches, teammate information and late recovery controls. Measure cue→choice→request→response, not yardage alone.

**Stop/revise:** players become permanently unaware, or “immutable inputs” still expose live opponents through captured objects. Do not add a global sensing delay to compensate. Evidence: [two possession routes](architecture.md).

### A06 — Stabilize coverage technique transitions

**Keep coverage purpose; broaden the execution-contract investigation, not the diagnosis. M per bounded correction. Owners: coverage; run/defense for their respective pursuit phases.** Preserve valid hip opening, depth and turn/run. Diagnose unsupported technique toggles separately from velocity redirection. P019's away-facing contact and P002's sweeping pursuit do not share a proven yaw cause.

For pursuit, first correct the `timeToReach`/`interceptPoint` contract: distinguish optimistic estimate, feasible candidate and fallback. Compare current requests with a bounded unchanged-capacity approach policy on transverse, aligned, slow-crossing and escaping targets, then native continuations. Preserve force, cutback, loaded-contact and head-on controls.

**Accept:** no promise violating the applicable necessary reach bound; useful approach improves without sacrificing faster crossings or alignment. A bound is not sufficient feasibility. **Stop:** two plausible local policies fail opposing controls; re-diagnose rather than widen gates. Keep capacity calibration open under A15. Evidence: [locomotion](locomotion.md), [native film](film-cases.md).

### A07 — Coherent dive/reach/acquisition

**Elevate shared geometry; M first slice, L adoption. Owner: defense with physics review.** Define origin/target landmarks, pose, center-to-reach meaning, finite body travel, acquisition instant and retained extension. Reconcile standing reach, lunge, dive and arrival consumers together. A future dive must not create a remote hold before its body motion occurs.

**Accept:** P048's invalid-envelope acquisition is removed or explained by explicitly modeled reachable movement; legitimate nearby contact and a reachable dive remain; receding/sideways/non-QB cases preserve misses and recovery costs. Reevaluate standing envelope disagreements without declaring every one anatomically impossible. A gate eliminating all dives fails.

Add an **S diagnostic** for falling-body throw release: fixed `z=2.2` currently ignores support/posture. Compare standing and falling launch geometry with a defensible reduced-body approximation; do not label all falling throws illegal. **Stop:** no anatomy expansion to solve either interface. Evidence: [contact investigation](contact.md).

### A08 — Responsibility/opportunity pilot

**Narrow and demote; M local comparison, L only if earned. Owner: run in a freed slot.** Preserve the existing first-threat policy. After the selected knowledge/execution boundaries are credible, compare it with the smallest role-specific help correction before a shared envelope. Nearby teammate position alone cannot represent observed down/rising/departing help, but a changed target is not automatically a better block.

**Accept:** native useful contribution improves on a reserved case while original cutback danger, useful co-moving help, unknown help, distant distractions and commitment remain. Use acquired information and physically attained opportunity. **Stop:** no native witness, no transfer beyond tuned cases, hidden-information advantage, or equivalent results from the smaller policy. The [local/envelope comparison](alternatives.md) supplies controls, not a production patch.

### A09 — Generalize to fit/rally and coverage

**Split: action-lifetime contract now, common chooser deferred. S implementation plus M semantics/transfer review. Owner: one run/coverage owner jointly reviewed.** Native P093 and P095 establish executed stale-target goals in two roles. Tie a cached goal to its active action episode. Either invalidate when an allowed target change ends the action, or hold target and goal together until commitment expires; decide per transition.

**Accept:** changed target, unchanged target, no new cue, expiry and A→B→A controls; preserve P029 and planned-climb nonconsumption. Native command/body effects should match the intended boundary without claiming outcome improvement. Do not accumulate target keys that revive an obsolete goal.

**Stop:** no extra scheduler. A common chooser needs a shared policy failure after these repairs; cache recurrence justifies a cache contract, not universal football semantics. Evidence: [native summaries](https://github.com/tannerthardy/football-simulation-/blob/73a800464a7b2a057a2f4df59d772c89bbd87b21/artifacts/audit-2026-10-25/Football-Sim-Deep-Audit.zip).

### A10 — Reusable short causal experiments

**Keep, combine with A04; M. Owner: tools.** Preserve exact pre-constructor setup, class/Map state, canonical actor identity, native prefix, intervention and censor/end state. Use the already neutral restorer for two consumers. A call and seed alone do not recreate the original game context.

**Accept:** repeat baselines match; the first changed command has identical upstream state and random state where claimed; retain unsuccessful interventions. Compare physical endpoints by stable actor identity. **Opposing control:** instrumentation alone changes nothing. **Stop:** if the harness does not shorten an active diagnosis, narrow it; no universal serializer or broad game campaign. Whole games test composition after the mechanism is isolated.

### A11 — Trait and actual-lineup contracts

**Move the truthfulness slice earlier; M. Owner: tools/player owner with football review.** Map exposed traits to capacity, recognition, technique, selection-only or unimplemented channels. Start with `leadBlock`, missing-versus-zero measurements and actual selected-personnel use. Separate roster selection effects from fixed-lineup execution.

**Accept:** the supported archetype panel changes its declared intermediate channel; recognition can change timing without granting speed, and technique affects an identifiable action without awarding success. Preserve plausible identical choices in obvious situations and tradeoffs across profiles. **Stop:** no requirement that every rating changes every play or improves final yards. Broader matchup claims wait for tested channels and A17 input identity.

### A12 — Small concept-installation family and transformations

**Keep; M installer checks, L first supported family. Owner: existing run/coverage/rules ownership.** Declare required roles, eligibility, spacing, timing and ownership for one family. **Accept:** missing required roles fail explicitly; valid poor calls fail through football, not silent reassignment; supported transformations preserve responsibility meaning. **Opposing control:** an intentionally overloaded or tactically poor installation remains expressible. **Stop:** exceptions multiply faster than supported cases, or installation quality is inferred only from yards. Broad tactical claims require credible execution, not a common chooser.

### A13 — Real protection call and exchange family

**Split preparation from physical adoption; M identification/ownership checks, L first family. **Accept:** ownership and transfer are explainable; a deliberately unblocked rusher remains a valid opposing case. Assignment tests need not wait for all G5 closure; full protection claims cannot bypass it.

### A14 — Bounded common-point hand-law repair

**Keep a bounded physics slot; L. Owner: physics/trenches.** Ordinary exposure strengthens the correctness priority, but the bundled common-patch mode changes several mechanisms and cannot isolate missing angular transfer. Separate angular Jacobian/transport from gait, yaw, torso timing and grasp-coordinate changes.

**Accept:** the law witness closes under fixed requests with refinement controls; current loaded football contacts preserve coherent work/budgets; runtime and native transfer are measured. Preserve a case where ground support makes added torque physically small. **Stop:** bundled-mode gains are offered as single-law proof, or visually improved facing substitutes for valid hand availability. Do not promise this repair resolves pursuit. Evidence: [contact law experiments](contact.md).

### A15 — Measurement versions, missingness and holdouts

**Keep early; S operator corrections, M usable panel, L/XL capability research. Owner: tools/data.** Use actual clocks, explicit roster eligibility, missingness and source hashes. Separate orientation from travel direction and filtered scalar deceleration from braking/cutting capacity. Reuse the better existing orientation and movement extractors.

**Accept:** isolated angle flips, smooth slow turns, missing rosters and terminal half-ticks cannot silently change the claimed population or capacity inference. Compare native response and tracking through matched operators; preserve provider-speed sensitivity separately. **Stop:** upper-tail observations are treated as hard biomechanical limits. Capacity remains unresolved until task/speed/contact-conditioned evidence and clean attainable controls support it. Preserve declared future holdouts; inspected cases become development evidence. See [measurement findings](measurements.md).

### A16 — Same-workload performance program

**Keep focused; M per useful optimization. Owner: tools/physics.** Profile completed production work with source, worker count, CPU/elapsed time and warm-up explicit. Start with allocation, storage, repeated observer work and compatible output reuse. Count existing previews before adding candidate searches; three native examples already use thousands of one-body prediction steps.

**Accept:** a specified experiment becomes cheaper with identical execution, or an explicitly reviewed semantic tolerance. **Opposing control:** equal short timing without equal completed work is not improvement. **Stop:** more forecast candidates add no transfer value, or reduced physics resolution is called an exact optimization. The [workload census](experiment-integrity.md) is not itself a throughput benchmark.

**Split: canonical inputs immediate, broad migration conditional. S normalization; M bounded stable keys; L/XL wider work. ### A18 — Adversarial matchup and exploit search

**Split: small controls now, broad search later. M local panel; L supported search. M3 is a prerequisite for broad claims, not a reason to defer today's small opposing controls.

### A19 — Richer attention, memory and communication

**Narrow now, defer speculative richness. M explicit acquired events; L/XL expansion. ### A20 — Full special teams, wider concepts and league

**Defer broad implementation; XL program with later bounded slices. Owner: future coaching/league and relevant football owners.** Keep capability boundaries visible. Kick coverage, returns, wider calls, coaching familiarity and roster evolution each need their own supported inputs, causal measures and cost budget.

**Accept before expansion:** a representative current matchup experiment is reproducible, interpretable and cheap enough for its intended workload. **Opposing control:** a structurally unsupported play cannot masquerade as a supported tactical loss. **Stop:** feature breadth consumes the owners required to close demonstrated execution defects. This audit adds no new league assignments.

### A21 — Full learned policies or anatomical solver expansion

**Keep parked; XL.** Require a bounded failure the current representation cannot express, defensible observations/objective or supervision, a cheaper baseline and production cost budget. Per-tick LLMs, full-team reinforcement learning and detailed feet are not prerequisites for the next milestone.

**Accept research entry:** the residual failure survives local knowledge, lifecycle, geometry and control repairs. **Opposing control:** the simpler policy retains its successful cases. **Stop:** a learned system exploits the simulator's invalid contact or information, or new anatomy is used to explain an untraced command. Preserve research without making it a delivery dependency.

## Dependencies, review decisions and stopping discipline

Real dependencies are local: carrier belief must reach both consumers; an obsolete-action correction needs a defined transition; acquisition requires agreed landmarks/time; useful pursuit evaluation requires a truthful forecast status and applied-command trace; capability claims require compatible measurements; meaningful lineup comparisons require stable input identity. Capture neutral native prefixes before interpreting interventions.

Other dependencies are organizational, not technical necessities. A cache fix need not wait for whole-engine perception migration. Installer tests need not wait for complete G5 closure. Contact-law correctness does not depend on A08. Traits can be inventoried before M2. Shared policy code is not a prerequisite for any of them. Coordinate common files and ownership through the existing review process, without turning the coordinator into every local test's approval gate.

For each material delivery, preserve the claim, first causal difference, strongest opposing result, remaining uncertainty and next decision in the PR. Use the smallest check that can change that decision, then the existing scorecard tiers for composition. Two failed mechanism attempts trigger re-diagnosis; a failed native transfer narrows the supported scope. Changes in final yards alone neither certify nor reject a correct mechanism.

Tanner's highest-value input remains ambiguous football judgment and product priority. Agents should first supply a short nominated clip, actual command/knowledge evidence and a credible alternative explanation. Track whether time from clip to isolated cause, repeated defect families and Tanner review burden improve. Fewer unexplained failures and more trustworthy experiments—not more abstraction or more paperwork—justify the next investment.
