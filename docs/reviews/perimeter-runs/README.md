## Refinement, with adverse evidence retained

1. **Buck mesh:** use the already available wide under-center exchange rather
   than the inside gap mesh. Isolated B01 gain falls2.29→2.03, with no guard load;
   a wider exchange alone does not establish better protection.
2. **Compatible pin-pull climbs:** greedy free-climber allocation sent H across
   loaded LT. Allocate the existing jobs together through the existing assignment
   matcher: LG/Mike and H/Will. Six early LT/H impacts and the later C/RB pair
   disappear in the isolated P01 arm. Gain falls1.43→1.27; the end still wins.
3. **Separate short kick from deep force:** a first-level kick must fit the
   approaching surface; deep outside support needs the perimeter corner followed
   by interception. The former rule chased a deep DB's width behind the line.
   Initial force entry turns up too soon, adding an RT/Z impact3.00 in C01 and
   a late C/RB impact in P01. Higher gains do not excuse those failures.
4. **Achieved corner:** waypoint tolerance alone is not clearance. The first
   guard version removes those collisions but deadlocks: steering stops .11yd
   inside a strict gate while aiming a stop exactly at that gate. Real-hook tests
   demonstrate that contradiction and a final-waypoint bypass. The final new-role
   correction puts the flat goal a body radius beyond its required boundary and
   prevents tolerance from skipping the gate. Wall clearance and normal spacing
   remain. Pullers resume movement; useful deep-force contact remains unproved.
5. **Information:** a real-hook test changes only the target's unobserved live
   engagement flag. It exposed retargeting of the new force job. Named new force
   work now uses acquired evidence like the new crack job; no shared awareness
   layer or old collection repair was duplicated.
