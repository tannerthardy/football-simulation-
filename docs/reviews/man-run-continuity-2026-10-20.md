# Keep acquired blocking support through coverage decisions

The repeated football error is **discarding an evidence-backed responsibility
when its original admission condition stops matching**. Corners recognize a
shallow blocking receiver and start run support. When that same acquired
low-pad receiver crosses LOS+2, `showsBlock` becomes false and they sprint
downfield in man coverage. The safety can then reinterpret the continuing
stalker as an uncapped vertical. Neither change requires contradictory evidence.

This correction preserves the accepted duty while current acquired blocking
evidence and run belief support it. It does not teach a universal shed, improve
hands, guarantee useful pursuit after separation, or establish that the long-run
tail is repaired. One ending remains materially adverse.

## Handoff and wider intelligence lesson

Publish this as an independent responsibility correction. Run should preserve
the explicit BackfieldRunFit distinction and the acquired-release controls when
composing its experiments; the shared reader change is part of this candidate.
Integration owns exact combined verification and acceptance. #169 remains a
separate engagement correction with its own evidence. Do not import Claude's
whole research branch or combine another selected-play variant here.

The reusable model is: installed duty → acquired interpretation → selected
purpose → constrained execution. Change purpose on legitimate new evidence or
an explicit responsibility handoff, not because an admission bound stopped
matching or contact changed the movement modifier. Lower awareness can delay a
read or sustain a wrong interpretation; unexplained erasure by another subsystem
is not realistic uncertainty. Analogous pull-fit and movement-objective problems
are documented in the evidence note as future questions, not fixed here.

The smallest next DB-owner question is whether a **supported held escape-side
choice** still leads toward an attainable support position as the runner moves,
versus the receiver physically securing that path. Use saved OZ4 renewed-contact
evidence first, preserve away-side escape and real blocks, and request more
passive force/entry evidence only if it changes that decision. No global grip
weakening, forced release deadline or universal commitment timer follows.
