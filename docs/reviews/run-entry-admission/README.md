# Runner entry: information correction and achievable approach admission

**Advance the information correction and this bounded approach correction
separately for Integration review. Keep the gap fix independent.** The original
RB/RG collision did not invalidate removing private engagement, fatigue and down
state from threat inference. Impact plus the fragile forecast held the complete
navigation improvement; collision alone did not establish bad football. That
classification is corrected at `3246009b951b28912599bb6ef93b4141505c0fc8` on
`codex/run-entry-cues`. The original traces/classification remain immutable.

The new approach uses the RB's complete own body, observer-owned teammate
pictures and public braking capability. It asks whether a path stays clear if a
teammate continues observed motion **or brakes along that same motion**, including
braking during the picture's already-extrapolated age. This is a directional
occupancy strip, not extra radius around every body, a promised future block,
or a request that the guard yield. It changes no physics/capability or sight/TTL.
Fast, existing half-speed and gather requests use the same native movement World
from the same own state; only desired velocity changes. The body still has to
brake and turn. No threshold or margin was fitted to P032.

## One adverse result, one diagnostic, one correction

Pacing a previously selected destination removed the RB/RG impact but left RB
alternating gather/half speed:0.65s of gather requests, no LOS crossing by3.00s.
We did not enlarge a margin or repeat the play with tuned thresholds.

One [saved-state diagnostic](route-diagnostic.json), at the repeated gather's
1.95s entry read, tested the existing ranked destinations with the same acquired
pictures and own state. The selected destination required gathering, while other
existing destinations had clear moving approaches: for example, the entry at
`(74.8,23.7743)` had a clear half-speed approach by0.09846yd. The selector compared
destination threat scores before checking whether their approaches were usable.
A non-traversing gather cannot be treated as arrival at that destination.

The final correction admits moving approaches before choosing the destination.
It keeps the original football-score order among usable entries, preserves the
original best entry immediately when it has a clear fast/slower approach, and
retains gather when no moving approach clears. It adds no detour angle menu,
forced sideways movement, guard-yield rule, defender suppression or yardage goal.
The movement model, .60s window, half-speed request and uncertainty envelope are
unchanged between the pacing-only and final trials.
