# Tackle package: legacy tests that change with the flags on (2026-11-24)

Run Game, run/tackle-repair. With TACKLE_REACH, LUNGE_FLIGHT, DIVE_STANCE and REACH_TIME all on, `npm test` (core + core-defaults, 4,461 tests) fails 120; with them off, 68 (the same 68 fail on develop 0226f0d3, Tools' count 71 with the Node pin; not this package's). So the package adds 53 and fixes 1. Each was rerun with each flag alone to name the cause. Decision: no test is retired; every one checks a contract that still holds, on a premise (instant attempt, legacy reach distance, one-tick dive, a recorded outcome) that the flags change. Nothing is skipped; at landing each is re-recorded by its owner.
