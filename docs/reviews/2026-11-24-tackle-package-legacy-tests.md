# Tackle package: legacy tests that change with the flags on (2026-11-24, updated)

Run Game, run/tackle-repair. With TACKLE_REACH, LUNGE_FLIGHT, DIVE_STANCE and REACH_TIME all on, `npm test` (core + core-defaults, 4,461 tests) failed 120 at 2311cb9e; flags off, 68, the same 68 as develop 0226f0d3 (not this package's). The package added 53 and fixed 1; each was rerun with each flag alone to name the cause. No test is retired or skipped; each checks a contract that still holds on a premise the flags change (an instant attempt, the legacy double-counted reach, a one-tick dive, a recorded outcome).

Re-recorded on the branch (Run Game's 28; flags off they are unchanged and pass):
- `test/helpers/tackle-now.ts`: `tackleNow` carries an attempt to its result (with REACH_TIME it steps the clock through the reach window; flag off it is `tryTackles`); `recordPicture` gives the tackler the staged scene as his perceived history (REACH_TIME's decision reads his picture).
- Fixture distances use `reachTo` (identical to the legacy sum with TACKLE_REACH off).
- pursuit-contact: a passing speed the timed reach can still meet where a full-reach grab is the subject; the whiff contract without the roll.
- tackle-wait-constraints: the extended-reach sanity check only where the arms reach past contact quality's full band (a blocked arm's 0.4 share under TACKLE_REACH does not).
- tackle-touch: TACKLE_TOUCH (off, an instant hold at standing reach) is measured on the legacy tackle it was defined on (the package's reach flags stubbed off in that file).
- hold-facing: with the package the pinned play (1957 DT_S) changes before the hold; the same bounds as a search over its scan range (finds 1936 DT_W, 165 -> 9 deg).
