See the [foundation and limits](delayed-possession-foundation.md).

**Draw presentation.** The installed initial pass presentation now survives

trigger real emergency contact. Existing owners retain their pass-set formula;
no strength or mandatory block win is added. The existing one-second phase is
authored technique, not a defender recognizing a play on a timer. See the

**Recovery finish.** An upright recoverer no longer gets an independent 75%
