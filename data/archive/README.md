# Archived evidence

The catalog pins generated files at commit `663193d` without rewriting history.
Run `python3 scripts/restore-evidence.py --list` to browse, then pass specific
paths or `--prefix` to restore into ignored `out/evidence-archive/`.

See the [data guide](../README.md) for film access, original-path restoration and
future storage. The previous catalog is a historical reference, not a work queue.
