## Reproduce and watch

Use Node22 and lockfile dependencies. From repository root:

```sh
node --import tsx scripts/diag/decision-awareness.ts out/awareness-new/passing.json.gz
python3 scripts/diag/decision-awareness-review.py data/reviews/decision-awareness/passing/baseline.json.gz out/awareness-new/passing.json.gz out/awareness-new/passing-comparison.json
node --import tsx scripts/diag/combo-transfer-review.ts out/awareness-new/runs.json.gz
python3 scripts/diag/run-outcome-review.py compare data/reviews/run-game-current/engine/final.json.gz out/awareness-new/runs.json.gz out/awareness-new/run-comparison.json
node --import tsx scripts/diag/offensive-awareness-probe.ts
node --import tsx scripts/diag/pass-installation.ts out/awareness-new/installation.json
node --import tsx scripts/calibrate.ts 2 7 1
```

The older audit probes have their original code/relative paths in `tools/`.
To rerun, copy `defense-probe.ts.txt` and `man-key-probe.ts.txt` to
`out/decision-awareness/defense/probe.ts` and `key-probe.ts`, and
`shared-probe.ts.txt` to `out/shared-decision-current/probe.ts`; then run with
`node --import tsx`. They write ignored output, never this published packet.
Their exact original versions/output pins are retained, including narrower
staged source phases; final broad controls belong to the final collectors.
The independent witness tool's original path is
`out/decision-awareness/final-witnesses/independent-native-review.ts`. It expects
the baseline source extracted from `632fb02` at
`out/decision-awareness/baseline-source`, with dependency access, and current
final source at repository root. It reproduces four outcome-selected pairs,
not another population panel. Its recorded paths reflect this workspace.

Download [the paired replay ZIP](../../../viewer/decision-awareness.zip),
extract and open `decision-awareness.html`. It contains twenty clips with
concept/front grouping, player/source IDs, inspection layers and video export.
It is standalone. Export anew from saved evidence without simulation:

```sh
node --import tsx scripts/export-combo-transfer.ts data/reviews/run-game-current/engine/final-film.json.gz data/reviews/decision-awareness/runs/final-film.json.gz out/awareness-new/replay.html data/reviews/decision-awareness/viewer-metadata.json
```

The manifest hashes every published packet file and the external source/tool,
review and replay identities. Prior packets are immutable; do not overwrite
them when collecting the next candidate.
