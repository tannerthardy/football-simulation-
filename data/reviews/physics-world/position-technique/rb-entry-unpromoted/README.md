# Unpromoted near-line RB corridor prototype

This is retained research, not the production carrier controller. Production `carrier.ts` was restored byte-for-byte from HEAD `80e8151`; the new test was removed from the production suite. No physics parameters or other owners’ source was changed.

The reproduced instruction problem is a wide far endpoint whose straight incoming path intersects a staggered blocker. The prototype keeps the same delayed adjacent-blocker pair and exit score, adds a near-face mouth waypoint, and checks a short production free-body movement preview before asking for full speed. It also tries to brake or choose a bounded escape when all approaches appear occupied. That latter policy is not sufficiently validated.

The useful narrow result is the same-pair mouth: the existing Duo directional-read test passes unchanged, rather than rejecting a valid bent approach merely because a straight ray to the far exit is obstructed. Genuine open lanes, delayed pictures, installed press instructions, shoulder-turned narrow creases, unavoidable-contact controls and exact mirrored capabilities are retained in the exploratory test.

The candidate was **not promoted**. The forecast omits the squeeze demand later sent to World and tests the runner’s present footprint rather than the achieved changing footprint. The one-body preview cannot prove a loaded or gripped runner’s approach clear, and the caller has not gated those states. Finally, the all-blocked braking/escape policy needs a native closing-penetrator control before it may suppress the existing generic evasion search.

Two exploratory assertions also fail: each late-braking mirrored runner makes one small real contact where the test expects none. That adverse contact must remain visible; it is not a reason to strengthen traction or erase incoming momentum. The existing Duo, run execution, boundary and contact-choice tests passed unchanged in the earlier focused run.

`manifest.json` pins exact baseline/candidate source, carrier, test and patch files. The `historicalFocusedResult` is explicitly a terminal summary from session 22518, not a fabricated raw log. Fresh isolated runs use the immutable baseline copy plus only this carrier replacement; their raw logs are retained separately. They do not measure NFL rates, full-play success or a production RB improvement.

Next bounded experiment: validate a reachable same-pair near-face mouth and its speed against the actual executed squeeze/shape and free-body guards, preserve the original installed outlet ranking, and prove a closing-penetrator escape before extending universal entry selection.
