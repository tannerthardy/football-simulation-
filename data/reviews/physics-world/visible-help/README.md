## Evidence and limits

- `panel-{before,pose-only,primary-stem}.json.gz` retain complete 24-play
  observations, initial/endpoint football contexts, generated profiles, all
  query-bearing fresh decisions and four predetermined R1/Cover 4 recordings
  per phase. Every observed/recorded endpoint matches an unrecorded control.
  Two artificial roster pairs, fixed calls, LOS 40 and an eight-second live
  limit are mechanics guards, not NFL population rates. The collector does not
  record substep work/force invariants or independently measure pressure.
- `comparison.json` is generated by `compare.py` from those saved archives.
  All initial football contexts match, pose-only has 24 exact endpoints, and
  the final change has 20 exact endpoints. Every altered case, live censor and
  adverse result remains. Added query-bearing records do not mean extra choices;
  only matched directive changes count as such. Natural completed field advance
  is not `buildResult` credited gain. Defensive possession and live endpoints
  have no imputed offensive gain. Engine pressure flags are copied, not validated.
- `../block-fit/coverage-cap-witness.json` is the staged before witness;
  `staged-pose-only.json` and `staged-final.json` preserve both later phases.
  A supplied primary directive with real delayed reading is not a full quarters
  controller installation. The upright control also loses cushion. The ordinary
  panel contains no grounded/rising cap misuse, so no field prevalence or broad
  explosive reduction is attributed to the pose cue.
- `early-stem-before-tests.log` intentionally has one failing regression on
  pose-only (12/13 pass); `early-stem-after-tests.log` has all 48 focused passes
  on final. `pose-only-tests.log` is the intermediate 645-test checkpoint,
  not the final suite. The additional tests check delayed pose, recovery,
  stale mistakes, missing cues, early own-stem responsibility and allowed help.
- `grasp-oracle.json.gz` measures isolated active torso-reel position through
  World. Collector success means domain and force/work checks passed; the
  Newtonian position check still fails all 24 active trials. All 24 passive
  controls pass. It excludes slipping, lower attachments and collision/support
  failure. No force constants are fitted and no football prevalence is inferred.
- `current-runs.json.gz`, `current-tackles.json.gz` and `current-games9.json`
  retain the broader guards against the same-named `../block-fit/` baseline.
  `transfer-validation.json` retains all 144 run pairs, all 64 tackle pairs,
  compact pose differences and both divergent games. Run execution and tackle
  physical paths/events/endpoints/RNG draws match exactly. Opaque tackle
  signatures include ring layout and therefore change. The two games still
  have excessive passing gain/YAC and adverse changes; they share initial
  inputs rather than subsequent calls or random draws. Timing is not a benchmark.
- The [HTML](../../../../viewer/visible-help.html) embeds eight paired ordinary
  films exported from saved raw archives without resimulation. It preserves
  actual finish versus live censor, stats, events and full telemetry. Ordinary
  position/facing packing alone is quantized. The selected R2 witness is in raw
  evidence outside these four predetermined film pairs. Body-facing ticks are
  not actual eye tracking. Missing pose in older films is supported.

## Reproduce

Use Node 22.23.3 and installed dependencies. Run full tests separately from
heavy simulation. Use explicit output paths; the staged collector's default
belongs to the older publication and should not be overwritten.

```sh
node --import tsx scripts/diag/coverage-help-review.ts out/visible-help/panel
node --import tsx scripts/diag/coverage-cap-review.ts out/visible-help/staged.json
node --import tsx scripts/diag/grasp-integration-review.ts out/visible-help/grasp-oracle.json
python3 data/reviews/physics-world/visible-help/compare.py data/reviews/physics-world/visible-help/panel-before.json.gz data/reviews/physics-world/visible-help/panel-pose-only.json.gz data/reviews/physics-world/visible-help/panel-primary-stem.json.gz out/visible-help/comparison.json
node --import tsx scripts/export-visible-help.ts data/reviews/physics-world/visible-help/panel-before.json.gz data/reviews/physics-world/visible-help/panel-primary-stem.json.gz out/visible-help/reproduced.html
node --import tsx scripts/diag/run-contact-review.ts out/visible-help/current-runs.json
node --import tsx scripts/diag/tackle-timing-review.ts out/visible-help/current-tackles.json.gz
node --expose-gc --import tsx scripts/diag/held-recovery-football.ts out/visible-help/current-games9.json 9 --games-only
node node_modules/vitest/vitest.mjs run --maxWorkers=1
node node_modules/typescript/bin/tsc -p tsconfig.json --noEmit
node node_modules/typescript/bin/tsc -p tsconfig.json
python3 -m unittest discover -s test -p 'test_*.py'
python3 data/reviews/physics-world/visible-help/transfer-validation.py
python3 data/reviews/physics-world/visible-help/verify-evidence.py --engine
```

For fresh paired panels, archive the publication commit into ignored scratch
checkouts and reuse dependencies. Reverse `engine.patch` in the before scratch
checkout; replace judgment with the retained intermediate bytes for pose-only.
Verify the three source hashes before running the unchanged collector. Never
replace the live checkout while another agent or a measurement uses it.
Container timestamps and gzip bytes may differ on regeneration; compare decoded
observations as well as archived provenance. No cost or full-game speed claim
is made from concurrently collected guards.

The verification manifest pins assets, collectors and check exit codes. Omit
`--engine` when inspecting this evidence after later source edits. Browser
validation uses the archived panel paths and local Chromium with network/font
requests blocked:

```sh
python3 data/reviews/physics-world/visible-help/film-check.py data/reviews/physics-world/visible-help/panel-before.json.gz data/reviews/physics-world/visible-help/panel-primary-stem.json.gz viewer/visible-help.html out/visible-help/film-check
```
