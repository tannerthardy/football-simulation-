## Rerun

Use Node 22.23.3 and installed dependencies. Run the full suite separately from
heavy simulations. Preserve published archives; write new measurements to
ignored output paths.

```sh
node --import tsx scripts/diag/ol-retarget-review.ts out/ol-retarget/new.json.gz
node --import tsx scripts/diag/run-contact-review.ts out/ol-retarget/new-runs.json
node --import tsx scripts/diag/tackle-timing-review.ts out/ol-retarget/new-tackles.json.gz
node --expose-gc --import tsx scripts/diag/held-recovery-football.ts out/ol-retarget/new-games9.json 9 --games-only
node node_modules/vitest/vitest.mjs run --maxWorkers=1
node node_modules/typescript/bin/tsc -p tsconfig.json --noEmit
node node_modules/typescript/bin/tsc -p tsconfig.json
python3 -m unittest discover -s test -p 'test_*.py'
python3 data/reviews/physics-world/ol-retarget/compare.py
python3 data/reviews/physics-world/ol-retarget/verify-evidence.py --engine
```

The comparison/verifier inspect the retained measurements without resimulation.
Omit `--engine` after later source/tool changes. Exact published bytes are
pinned; regenerated timestamps/gzip bytes can differ without changing decoded
execution. For a baseline measurement, archive the baseline commit into an
ignored scratch checkout, reuse dependencies, and copy the exact same collector
there. Verify the engine hash before measuring. Do not overwrite live source
during another agent's work or a running simulation.

Film export and browser rerun arguments are documented in
`scripts/export-ol-retarget.ts` and `film-check.py`. Both consume saved recordings
only; browser verification uses Python Playwright/Chromium and an internal local
server. The native trace's controller time and completed-step load must retain
their stated convention rather than inventing a later decision.
